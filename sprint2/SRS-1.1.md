## 1. Вступ

### 1.1 Призначення
Документ визначає функціональні, інтерфейсні, бізнес-логічні та нефункціональні вимоги до системи управління персоналом «Персонал+» і є основою для тест-кейсів, автоматизації перевірок та приймання продукту.

### 1.2 Обсяг
Охоплено модулі поточної версії: вхід, Admin (користувачі), PIM (працівники), Leave (відпустки), Time (табелі), Recruitment (вакансії, кандидати), My Info, а також Java-модуль бізнес-логіки (відпустки, нарахування, перевірка даних працівника). Модулі Performance, Directory, Claim і Buzz у версії 1.0 не специфікуються.

### 1.3 Терміни і скорочення

| Термін | Визначення |
| :--- | :--- |
| HRM | Система управління персоналом (Human Resource Management). |
| PIM | Модуль обліку працівників (Personal Information Management): список, додавання, профілі. |
| ESS | Самообслуговування працівника (Employee Self Service): власні дані, заявки, табелі. |
| Табельний номер (Employee Id) | Унікальний ідентифікатор працівника; призначається під час додавання. |
| Ліміт відпустки (entitlement) | Дні відпустки певного типу, призначені працівникові на період відпусток. |
| Баланс відпустки | Ліміт мінус використані, заплановані дні та дні у заявках, що очікують погодження. |
| **Період відпусток (leave period)** | **Проміжок часу, на який призначаються ліміти відпусток; у поточній версії — календарний рік (01.01–31.12).** *[1.1, дефект 4]* |
| Табель (timesheet) | Тижневий облік годин за проєктами і видами робіт. |
| РНОКПП | Реєстраційний номер облікової картки платника податків (10 цифр). |

### 1.4 Посилання
1. «Персонал+». Опис продукту, ролей і бізнес-процесів (Досьє якості, розділ 1).
2. «Персонал+». Модуль бізнес-логіки: README до версій 1.0.0 і 2.0.0 (code/modules/personal).
3. Поточна версія продукту (demo-стенд): https://opensource-demo.orangehrmlive.com.

## 2. Загальний опис

### 2.1 Користувачі та ролі

| Роль | Права та типові дії |
| :--- | :--- |
| Працівник | Власний профіль (My Info), заявки на відпустку, баланс, табель. |
| Керівник підрозділу | Усе, що працівник, а також погодження заявок на відпустку і табелів підлеглих. |
| HR-менеджер | Облік працівників, ліміти й призначення відпусток, вакансії та кандидати. |
| Адміністратор | Усе, що HR-менеджер, а також облікові записи користувачів і довідники. |

У поточній версії ролі «Керівник підрозділу» і «HR-менеджер» реалізовані через роль користувача Admin, «Працівник» — через ESS. Тестовий обліковий запис адміністратора: Admin / admin123.

### 2.2 Середовище
Вебзастосунок; клієнт — актуальні версії Chrome або Firefox, роздільна здатність не менше 1280×720. Поточна версія розгорнута за адресою з п. 1.4 (маршрут входу /web/index.php/auth/login). Інтерфейс поточної версії англомовний: назви елементів і статусів наведено так, як на екрані. Формат дат у полях і в підказці поля дати — yyyy-dd-mm.

### 2.3 Обмеження і припущення
- Дані demo-стенду періодично скидаються; створені записи не зберігаються між сеансами тестування.
- У версії 1.0 немає інтеграцій із зовнішніми сервісами (SMS-шлюзи, месенджери, державні реєстри, портали вакансій) і мобільного застосунку.
- Модуль бізнес-логіки — окремий Java-проєкт (JDK 17, Maven) без графічного інтерфейсу; його правила перевіряються юніт-тестами.
- Ставки податків і норми розділу 5 — параметри конфігурації; наведені значення чинні для 2026 року.

## 5. Вимоги до бізнес-логіки модуля

Модуль — Java 17, пакет `ua.kpi.tzyapz.personal`, класи `LeaveCalculator`, `PayrollCalculator`, `EmployeeValidator`. Дати — `java.time.LocalDate`; суми — у гривнях, `java.math.BigDecimal`, округлення `HALF_UP` до 2 знаків (копійок). Некоректні аргументи (від'ємні значення, відсутні дати) — `IllegalArgumentException`.

Параметри модуля (публічні константи класів): `ACCRUAL_PER_MONTH` = 2 дні, `MAX_ACCRUAL_PER_YEAR` = 24 дні, `MAX_CARRY_OVER` = 5 днів (BL-10, BL-20); `PIT_RATE` — ставка ПДФО = 18 %, `MILITARY_RATE` — ставка військового збору = 5 % (BL-50); `HOURS_PER_MONTH` = 168, `OVERTIME_COEF` = 1,5 (BL-60, BL-70); `MIN_AGE_YEARS` = 16, `TAX_ID_LENGTH` = 10 (BL-80).

| ID | Формулювання | Пріоритет |
| :--- | :--- | :-: |
