```text
sprint3/
├── README.md            # Паспорт: трекер, статистика, покриття «вимога → TC», DoD, сценарій Demo
```

* **Мітки:** `severity:blocker` … `severity:trivial`, `priority:P1` … `priority:P3`, `status:new` / `status:open` / `status:rejected` / `status:deferred` / `status:fixed` / `status:verified` / `status:reopened`, `sprint:3`. * **Зв'язок:** у тексті issue — TC і вимога; у `test-cases.xlsx` — стовпець «Bug ID / issue»; у журналі — Bug ID для кожного failed.
