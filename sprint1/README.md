## 3. Змодельовані бізнес-процеси (BPMN 2.0)

Моделювання виконано в інструменті **diagrams.net (draw.io)**. Усі діаграми доступні у двох форматах: `.drawio` (редагований XML) та `.drawio.png` (векторно-растровий графічний експорт):

1. **Модель 1: «Подання й погодження відпустки»**
   - Вихідний файл: [`bpmn/01_leave_approval.drawio`](bpmn/01_leave_approval.drawio)
   - Графічний експорт: [`bpmn/01_leave_approval.drawio.png`](bpmn/01_leave_approval.drawio.png)
   - _Елементи:_ 4 доріжки, 2 шлюзи XOR, граничний переривний таймер 3 дні (ескалація до HR), розгорнутий підпроцес розрахунку днів.

2. **Модель 2: «Облік робочого часу (табель)»**
   - Вихідний файл: [`bpmn/02_timesheet.drawio`](bpmn/02_timesheet.drawio)
   - Графічний експорт: [`bpmn/02_timesheet.drawio.png`](bpmn/02_timesheet.drawio.png)
   - _Елементи:_ 4 доріжки, початковий таймер кінця періоду, проміжний непереривний таймер нагадування (2 дні), цикл повернення на доопрацювання.

3. **Модель 3: «Звільнення співробітника (Offboarding)»**
   - Вихідний файл: [`bpmn/03_offboarding.drawio`](bpmn/03_offboarding.drawio)
   - Графічний експорт: [`bpmn/03_offboarding.drawio.png`](bpmn/03_offboarding.drawio.png)
   - _Елементи:_ 5 доріжок, паралельний шлюз ТА (розгалуження на керівника, адміна, бухгалтерію) та синхронізуючий шлюз ТА, підпроцес нарахування виплат.

## 4. Виконання нормативів Definition of Done (DoD)

- [x] **Кількість моделей BPMN 2.0:** 3 штуки (норматив для 4 осіб виконано);
- [x] **Формати моделей:** `.drawio` + `.drawio.png` у папці `bpmn/`;
- [x] **Складність діаграм:** використано XOR, Parallel AND, граничні події-таймери та підпроцеси;
- [x] **Таблиці специфікацій елементів:** присутні повні таблиці «крок — тип — опис» у `product.md`;
- [x] **Беклог вимог:** 14 User Stories (вимога $\ge 12$) за INVEST із детальними примітками для тестування;
- [x] **Матриця простежуваності:** 100% покриття всіх 6 очікувань замовника історіями користувача;
- [x] **Розподіл задач:** заповнено `tasks.md` із плановими та фактичними годинами, закріпленими виконавцями та взаємними рецензентами;
- [x] **Статут і ретроспектива:** зафіксовано у `docs/team/charter.md` та `sprint1/retro.md`.
